# File processor

A python CLI tool that reads, cleans, and consolidates data from TXT, CSV, Excel and JSON files to automate file organization.

## Features

- Supports multiple file formats: .txt, .csv, .xlsx, .json
- Object-Oriented architecture using Abstract Base Classes (ABC)
- Built-in validation to prevent overwriting input files
- Centralized logging system

## Technologies Used

- Python 3.x
- Pandas (for Excel/Csv handling)
- OpenPyXl (For Excel file support)

## How to run

1. Clone this repository:
   git clone https://github.com/Keiderdaniel/oop-data-processor 

2. Install dependencies:
    pip install -r requirements.txt

3. Run the program
    python main.py
